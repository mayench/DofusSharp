# Iconos de hechizos

La interfaz busca primero iconos PNG originales aquí, por identificador de hechizo:

- `yopuka-pressure.png`
- `yopuka-intimidation.png`
- `yopuka-divine-sword.png`
- `yopuka-sword-of-yopuka.png`
- `ocra-magic-arrow.png`
- `ocra-retreat-arrow.png`
- `ocra-icy-arrow.png`
- `ocra-burning-arrow.png`

Si un archivo no está, el cliente dibuja un glifo elemental de sustitución. No se incluyen
imágenes del cliente de Ankama en este repositorio; antes de distribuirlas hay que comprobar
su licencia y atribución. Para una tipografía local opcional, coloca `DofusRetro.ttf` en
`Assets`; si no existe, la aplicación intenta usar Georgia instalada en Windows.
